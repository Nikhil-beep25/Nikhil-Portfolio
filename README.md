## 🌟 Overview

Welcome to the **Minecraft Developer World** of **Nikhil Bhadauriya** — a full-stack software engineer, AI enthusiast, and tech educator.

This project transforms the traditional developer portfolio into an interactive, gamified sandbox experience inspired by **Minecraft**. Rather than scrolling through flat resume bullet points, visitors step into a procedural voxel landscape equipped with custom Web Audio sound synthesis, a working 3x3 crafting table, inventory chests with item rarity tiers, an advancement achievement tree, a dynamic day/night celestial cycle, and an interactive XP leveling engine.

---

## 🎮 Key Features & Gameplay Mechanics

### 1. ⏳ Chunk-Loading Cinematic Intro
- Authentic dirt-textured Minecraft loading progress bar.
- Procedural splash texts and witty game tooltips (*"Summoning code blocks...", "Placing redstone torches...", "Optimizing database queries..."*).
- An interactive **"Enter World"** gate with retro audio feedback.

### 2. 🌅 Dynamic Day / Night Celestial Cycle
- Real-time celestial transitions between **Sunlit Grasslands** and **Moonlit Woodlands**.
- Night mode features ambient darkness, twinkling stars, and floating animated fireflies.
- Synchronized lighting across all UI blocks and 3D voxel objects.

### 3. 🎒 Inventory Chests & Shulker Loot (Projects)
- Projects presented as inventory item slots with RPG rarity tiers:
  - 🟡 **Legendary** — Flagship systems
  - 🟣 **Epic** — Advanced full-stack platforms
  - 🔵 **Rare** — Specialized production tools
- Item hover tooltips displaying lore, attributes, tech tags, and links to live demos and GitHub repositories.

### 4. 🔨 Interactive 3x3 Tech Crafting Bench (Skills)
- A fully functional **3x3 Crafting Table** grid!
- Click and combine tech ingredients in the crafting matrix to discover real projects and capabilities:
  - `React` + `TypeScript` + `PostgreSQL` ➔ **NagrikSetu** (Civic Services Gateway)
  - `React` + `Node.js` + `PostgreSQL` ➔ **VidyaSanchar ERP** (Institutional Management)
  - `React` + `Node.js` + `MongoDB` ➔ **CarVerse** (Vehicle Fleet Reservation)
  - `Python` + `Gemini API` + `FastAPI` ➔ **GenAI Intelligence Engine**
  - `React` + `Tailwind CSS` + `TypeScript` ➔ **Minecraft Portfolio**
- Authentic item pickup, slot placement, and crafting sound effects.

### 5. 🏆 Advancements & Quest Timeline
- Modeled after the classic Minecraft Advancement tree (`Challenge`, `Goal`, and `Regular` ribbons).
- Tracks professional milestones:
  - ⚔️ **MERN Full Stack Apprenticeship** @ DUCAT India
  - 🍎 **Full Stack Developer Trainee (Python & GenAI)** @ S O Infotech
  - 🎓 **Bachelor of Computer Applications (BCA)** @ Dr. Bhimrao Ambedkar University (DBRAU)

### 6. ⚔️ Hotbar HUD & XP Leveling Engine
- Fixed-bottom 9-slot Minecraft Hotbar HUD for quick navigation between page chunks.
- Sound-reactive slot changes with tool selection feedback.
- Dynamic **Experience Bar (XP Bar)** that fills as you scroll through chunks of the portfolio, granting bonus levels upon discovery.

### 7. ⛏️ Clickable Bedrock Footer & XP Mining
- Interactive voxel blocks at the bedrock layer.
- Visitors can click and "mine" blocks to farm XP points with particle crunch effects and leveling chimes.

### 8. 🏕️ Woodland Campsite & Inquiry Terminal
- Cozy campfire campsite with animated embers and torchlight.
- Interactive parchment scroll contact terminal connected to an Express backend with automated email delivery via Resend.

### 9. 🔊 Procedural Web Audio Engine
- Built directly on top of the native **HTML5 Web Audio API**.
- Zero external MP3/WAV assets to load — 100% synthesized 8-bit square, saw, and noise waveforms for instant response with zero copyright liability.

### 10. 🧊 Hybrid 3D Voxel Engine (Three.js & React Three Fiber)
- Three-dimensional floating artifacts, voxel lighting, and post-processing depth effects.
- Graceful low-power fallbacks for mobile and battery-constrained devices.

## 🛠️ Tech Stack & Architecture

### Frontend
- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) + Custom Pixel Art & Voxel CSS
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://r3f.docs.pmnd.rs/) + [@react-three/drei](https://github.com/pmndrs/drei)
- **Icons**: [Lucide React](https://lucide.dev/) + [React Icons](https://react-icons.github.io/react-icons/)
- **Audio**: Custom Procedural Web Audio Synthesizer (Zero asset dependencies)

### Backend
- **Runtime**: [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/)
- **Email Delivery**: [Resend API](https://resend.com/)
- **Configuration**: `dotenv`, `cors`

### Hosting & Infrastructure
- **Frontend**: [Vercel](https://vercel.com/) (Edge CDN with automatic SSL)
- **Backend API**: [Render](https://render.com/)

## ⚡ Getting Started

Follow these steps to run the Minecraft Portfolio locally on your machine.

### 📋 Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** or **yarn** / **pnpm**
- Modern web browser with WebGL and Web Audio API support (Chrome, Firefox, Edge, Safari)

### 📥 1. Clone the Repository
```bash
git clone https://github.com/Nikhil-beep25/Nikhil-Portfolio.git
cd Nikhil-Portfolio
```

### 📦 2. Install Dependencies
```bash
npm install
```

### ⚙️ 3. Configure Environment Variables
Create a `.env` file in the root directory (or inside `backend/` if configuring the server separately):

```env
# Server Port
PORT=5001

# Resend API Key for contact form emails (optional for local browsing)
RESEND_API_KEY=your_resend_api_key_here
CONTACT_EMAIL=nikhilbhadauriya2500@gmail.com
```

### 🚀 4. Run the Development Environment
Launch both the backend API server and the Vite client simultaneously:

```bash
npm run dev
```

- **Frontend Client**: `http://localhost:5173`
- **Backend API**: `http://localhost:5001`

*(Or run only the client with `npm run dev:client`)*

### 🏗️ 5. Build for Production
```bash
npm run build
```
This runs TypeScript checks (`tsc -b`) and produces an optimized production bundle inside the `dist/` directory.
